Nowhere Protocol
================

An open, implementation-independent Wire Protocol for secure TCP and UDP
forwarding. NW3 is the current Wire version, based on TLS 1.3 and QUIC;
its ALPN is nw3.

Contents
--------
README.md    Overview and licensing
PROTOCOL.md  Core Wire specification
LICENSE      CC BY 4.0 license text

This repository provides a specification, not an implementation. The
extraction preserves the existing NW3 Wire format, authentication,
cryptographic labels and transport semantics.

NodePassProject/Nowhere provides a Rust implementation of NW3.
